Slide Type Showcase

Eight layouts show how this skill can tell different stories.

This reference deck uses the Gen-e2 Light theme to demonstrate the default slide types available in the HTML presentation skill, with one example per layout and a short note on when to use it.

Single Big Number

Use one number when the takeaway is already obvious.

68%

of stakeholders remember the stat when nothing else competes with it

Use when

One KPI or outcome is the whole point. Keep supporting text to a single sentence and let the number do the work.

Gen-e2™

Two-Column Split

Use a side-by-side frame when the audience must compare trade-offs.

Option A: Faster Launch

  • Lower upfront effort
  • Reuses current workflows
  • Shorter learning curve

Option B: Stronger Platform

  • Higher long-term scalability
  • Cleaner data model
  • Better automation potential
Use when

Comparing before and after, option A and B, or current and future state. Give both sides equal visual weight so the choice feels credible.

Gen-e2™

2x2 Matrix

Use a matrix when priority depends on two competing dimensions.

Higher impact

Quick wins

High impact, low effort actions to start immediately.

Strategic bets

High impact, high effort moves that need sponsorship.

Fill-ins

Low impact, low effort tasks to batch or automate.

Avoid

Low impact, high effort work that should not lead the plan.

Lower effort → higher effort
Use when

Prioritisation or trade-off mapping. Label the axes clearly and keep each quadrant to one decision-ready idea, not a list dump.

Timeline / Phased Roadmap

Use a phased view when the sequence is as important as the work.

Phase 1

Prove value

Pilot the smallest viable release and validate adoption.

Phase 2

Stabilise ops

Standardise the workflow, governance, and reporting.

Phase 3

Scale usage

Expand the footprint across teams and customer segments.

Phase 4

Optimise value

Automate improvement loops and tune the economics.

Use when

Sequencing a strategy, transformation, or release plan. Show no more than four phases on one slide unless the detail truly changes the decision.

Quote Pull

Use a quote when one voice captures the case better than analysis.

The hardest part is not the feature set. It is helping teams trust a new way of working.

Head of Delivery, transformation sponsor interview

Use when

Customer voice, executive signal, or a memorable line from research. Keep it under three lines and make the attribution specific enough to feel real.

Three Cards / Pillars

Use three pillars when the strategy rests on parallel themes.

Pillar 01

Adopt

Get the first teams using the new model with confidence and speed.

Pillar 02

Enable

Provide the tooling, guardrails, and data needed for scale.

Pillar 03

Sustain

Measure outcomes and close the loop so the model keeps improving.

Use when

Three parallel strategic themes, value pillars, or workstreams. This layout breaks when the themes are not truly equal, so do not force it.

Gen-e2™

Process Flow

Use a flow when the hand-off path matters more than the detail.

Step 01

Trigger

A need, request, or signal starts the process.

Step 02

Triage

Assess the path, owner, and urgency before work begins.

Step 03

Execute

Complete the task with clear ownership and visible status.

Step 04

Confirm

Close the loop, capture evidence, and move to the next item.

Use when

Sequential steps with clear hand-offs. Avoid branching logic on the first pass; if the process forks heavily, move to a dedicated flow diagram.

Gen-e2™

Feature Grid

Use a grid when the audience needs a quick scan across many items.

01

Dashboard

Snapshot of health, KPIs, and exceptions.

02

Alerts

Real-time triggers for risk or escalation.

03

Workflow

Guided task progression with ownership states.

04

Analytics

Trend views for decisions and optimisation.

05

Permissions

Role-based access for governance and control.

06

Integrations

Connectors that reduce duplicate work and re-entry.

Use when

Up to six items that are meant to be scanned, not debated one by one. Keep the cards short or split into multiple slides.

The Ask

Choose the slide type in your prompt before generating the full deck.

From the user, before generation. Name the layout you want, the point it must land, and the skill can shape the slide around that story with much less rework.

Prompt cues
  • Use a big-number slide to show the core KPI.
  • Use a 2x2 matrix to prioritise the options.
  • Use a feature grid to scan the MVP scope.
